# Reporting a problem

Please report a reproducible issue with the version, OS and a reviewed,
redacted report. Do not attach raw snapshots, credentials, private server names
or unrelated environment variables to public issues.

BEFORE does not need administrator privileges for its normal workflow. It does
not execute entered commands, PAC files, scripts from snapshots or a repair
command. Imported snapshots are data and are size-checked and validated.

An external connectivity check contacts the selected host directly and may
deliberately bypass an explicit proxy. Enable it only when that is appropriate
for the network you are using. The application does not disable TLS verification.
