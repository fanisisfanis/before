# Changelog

## 0.1.0

- English-first interface and reports with an immediate Russian language switch.
- Native desktop UI for saving, selecting and comparing local working states.
- Windows and Linux read-only collectors for proxies, PATH, commands, hosts and
  a deliberately small set of network services.
- Deterministic findings with evidence, explicit uncertainty and next steps.
- Loopback-only local proxy checks and optional bounded HTTPS route comparison.
- Editable, redacted Markdown / standalone HTML report export.
- Validated snapshot import/export and transactional local SQLite history.
- CLI, reproducible scenario suite, desktop integration checks and native build workflow.
