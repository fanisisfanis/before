# BEFORE · Вчера работало

Приложение для ПК, которое сохраняет рабочие настройки и помогает увидеть,
что изменилось после поломки. Основной язык — английский; русский включается
кнопкой **РУС** внутри приложения или параметром `python run.py --lang ru`.
Версия 0.1.0.

## Быстрый запуск

**Готовая Linux-версия:** распакуй папку `BEFORE`, открой находящийся в ней
исполняемый файл `BEFORE`. Папка `_internal` должна лежать рядом. Если файловый
менеджер снял право запуска, выполни в этой папке:

```bash
chmod +x BEFORE
./BEFORE
```

Это x86-64 сборка с включённым Python. Нужна обычная графическая среда Linux с
glibc 2.39 или новее и системными библиотеками Qt для X11/Wayland/OpenGL.
Сборка предназначена в том числе для современных x86-64 установок Arch Linux.
На конкретной установке Arch этот выпуск ещё не проверялся.

**Windows из исходников:** установи Python 3.10–3.13 с [python.org](https://www.python.org/downloads/),
затем открой `start.cmd`. При первом запуске он создаст виртуальное окружение и
скачает PySide6. Для Windows `.exe` в проекте есть готовый сценарий сборки и
GitHub Actions; готовая Windows-сборка в начальный комплект не входит.

**Linux из исходников:** Python 3.10–3.13 и команда `./start.sh`. Если скрипт не
исполняется, сначала `chmod +x start.sh`. После первой установки зависимости
приложение запускается без интернета.

## Как пользоваться

1. Когда нужные программы работают, нажми **Сохранить состояние** и дай снимку имя.
2. Когда что-то сломалось, выбери этот снимок слева и нажми **Сравнить сейчас**.
3. В разделе **Интернет** проверь прокси; отдельной галочкой можно включить
   прямой HTTPS-запрос и запрос через прокси к указанному сайту.
4. В разделе **Команда** введи имя вроде `python` или `ffmpeg`. BEFORE найдёт
   файл в PATH, не выполняя саму команду. Для собственной команды можно заранее
   сохранить снимок с введённым именем, чтобы было с чем сравнить.
5. Открой доказательства и следующий шаг. Кнопка **Отчёт** даст отредактировать
   текст и сохранить его в HTML или Markdown.

Сохранённый снимок можно экспортировать или удалить правой кнопкой мыши в
списке слева. Импорт принимает JSON-снимки BEFORE размером до 2 МБ.

## Что приложение действительно умеет

- Читает прокси, PATH, доступность команд, hosts и выбранные сетевые службы.
- Показывает точные старые и новые значения.
- Разделяет факт и предположение, явно отмечает недоступные данные.
- Проверяет порт настроенного локального прокси.
- По отдельному включению сравнивает HTTPS-подключение напрямую и через
  поддерживаемый прокси; общий лимит внешней проверки — 12 секунд.
- Хранит историю локально и создаёт отчёт с предпросмотром.

Снимки создаются вручную. Linux видит PATH и прокси своего запущенного процесса;
после изменения окружения в терминале BEFORE нужно перезапустить из этого
окружения. Windows заново читает PATH из реестра, но уже открытые терминалы могут
иметь другое значение. Запуск команд, aliases и функции shell не проверяются.

Запись в hosts или отключение службы может быть намеренным: приложение не
объявляет это причиной без дополнительных данных. Настройки ОС оно не меняет.
Автоисправление, драйверы, BSOD, аппаратные неисправности, PAC-скрипты и настройки
прокси каждого отдельного браузера в этот MVP не входят.

## Данные

Снимки: `%LOCALAPPDATA%\Before` на Windows и `~/.local/share/before` на Linux
(либо каталог `XDG_DATA_HOME`). Удаление этой папки сбрасывает локальную историю.

Снимки содержат локальные пути и адреса. Пароли в URL прокси и параметры URL
удаляются перед сохранением. Перед отправкой отчёта проверь предпросмотр:
домены и адреса серверов могут остаться. Отчёт можно исправить вручную.
Никакая кнопка не отправляет снимок или отчёт в облако.
